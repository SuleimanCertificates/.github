## Təşkilatın Repozitoriyaları

Bu layihə iki əsas arxitektur hissədən ibarətdir:

### 1. [SuleimanCertificates.github.io](https://github.com/SuleimanCertificates/SuleimanCertificates.github.io)
**Rəsmi Vitrin Veb Saytı**
* **Veb Sayt**: [https://suleimancertificates.github.io/](https://suleimancertificates.github.io/)
* **Xüsusiyyətlər**:
  - Bento Grid və Compact List baxış rejimləri
  - Qaranlıq və İşıqlı rejim dəstəyi (Dark / Light Theme)
  - Real-vaxt canlı axtarış və klaviatura naviqasiyası (Ctrl+K / Cmd+K)
  - HTML5 dialoq əsaslı yüksək dəqiqlikli sənəd baxışı (Zoom, Fullscreen)
  - Core Web Vitals (CWV) optimizasiyası
  - Hər bir sertifikat üçün fərdi statik URL səhifəsi və Credential ID kopyalama imkanı

### 2. [SuleimanCertificates](https://github.com/SuleimanCertificates/SuleimanCertificates)
**Mərkəzi Məlumat Bazası, Rəsmi Sənədlər və REST API**
* **data/**: 34 sertifikatın ikidilli strukturlaşdırılmış JSON verilənlər bazası və formal JSON sxemi
* **documents/**: Orijinal rəsmi PDF sənədləri və yüksək keyfiyyətli JPG/PNG sertifikat təsvirləri
* **backend/**: Node.js və Express əsaslı REST API servisi
* **Docker**: İstehsalat mühiti üçün konteyner konfiqurasiyası
* **Skriptlər**: Məlumat bütövlüyünün yoxlanılması (validate.js), analitika generasiyası (generate-stats.js), SEO generasiyası (build-seo.js) və sinxronizasiya (sync-frontend.js)
