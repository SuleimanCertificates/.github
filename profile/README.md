## 🌐 Təşkilatın Əsas Repozitoriyaları (Core Repositories)

Bu təşkilat iki əsas memarlıq qatından ibarətdir:

### 1. 🎓 [SuleimanCertificates.github.io](https://github.com/SuleimanCertificates/SuleimanCertificates.github.io)
**Rəsmi Vitrin Veb Saytı (Public Showcase Platform)**
* 🌐 **Canlı Veb Sayt**: [https://suleimancertificates.github.io/](https://suleimancertificates.github.io/)
* **Xüsusiyyətlər**:
  - Bento Grid və Compact List baxış rejimləri
  - Ağıllı Qaranlıq və İşıqlı rejim (Dark / Light Theme)
  - Real-vaxt canlı axtarış və qlobal `⌘K` / `Ctrl+K` qaynar düyməsi
  - Doğma HTML5 `<dialog closedby="any">` lightbox modalı (Zoom, Fullscreen, klaviatura naviqasiyası)
  - Core Web Vitals (CWV) üçün `fetchpriority="high"` və `loading="lazy"` optimizasiyası
  - Hər sertifikat üçün birbaşa dərin keçid (deep linking `#cert-id`) və 1-kliklə Credential ID kopyalama

### 2. 🏛️ [SuleimanCertificates](https://github.com/SuleimanCertificates/SuleimanCertificates)
**Mərkəzi Data Anbarı, Sənədlər və REST API Backend (Master Data Vault)**
* 📁 **`data/`**: 32 sertifikatın ikidilli tam JSON verilənlər bazası və formal JSON Schema
* 📄 **`documents/`**: Bütün 30+ orijinal rəsmi PDF sənədi və 32 yüksək keyfiyyətli JPG/PNG sertifikat təsviri
* ⚡ **`backend/`**: Node.js & Express REST API (`/health`, `/api/certificates`, `/api/categories`, `/api/stats`, `/api/certificates/:id/pdf`)
* 🐳 **Docker**: İstehsal üçün `Dockerfile` və `docker-compose.yml`
* 🛠️ **CLI Skriptləri**: Avtomatlaşdırılmış schema yoxlanışı (`validate.js`), analitika generasiyası (`generate-stats.js`) və frontendi yeniləmə (`sync-frontend.js`)
